<h3>MSB ATM System (CS5500 Software Engineering)</h3>
<ul>
  <li>
    <strong>Description:</strong>
    A full multi-phase software engineering project to design and implement
    an ATM system for <em>Montana Savings Bank (MSB)</em>, including requirements analysis,
    UML design, and a C++ implementation. The final document includes
    requirements/specification, class diagrams, communication diagrams,
    use case specifications, and implementation sections.
  </li>

  <li>
    <strong>Key Features / Requirements:</strong>
    <ul>
      <li>ATM supports withdrawals, deposits, transfers, balance inquiry, and receipts.</li>
      <li>Business rules include a $500 daily withdrawal limit and $10 withdrawal multiples.</li>
      <li>Non-MSB customers may be charged a $3.50 fee per transaction.</li>
      <li>
        Account types include Checking, Savings, Money Market, Consumer Loan,
        Mortgage, and CD (balance inquiry only).
      </li>
    </ul>
  </li>

  <li>
    <strong>What’s Included:</strong>
    <ul>
      <li>
        Final specification and design document PDF containing table of contents,
        use cases, UML diagrams, and code sections.
      </li>
    </ul>
  </li>
</ul>

<h3>Book Lab (BookType + BST)</h3>
<ul>
  <li>
    <strong>Description:</strong>
    A data structures lab implementing a <strong>BookType</strong> class and a
    <strong>Binary Search Tree (BST)</strong> to store, search, and traverse book records
    ordered by ISBN using overloaded operators.
  </li>

  <li>
    <strong>Files:</strong>
    <ul>
      <li>
        <code>BookType.h</code> / <code>BookType.cpp</code> – book data model with dynamic
        author arrays and ISBN comparisons.
      </li>
      <li>
        <code>BookTypeBST.h</code> / <code>BookTypeBST.cpp</code> – BST insertion,
        search, and inorder traversal.
      </li>
      <li>
        <code>TestBookType.cpp</code> – driver program that generates books,
        inserts them into the BST, and prints ISBNs in sorted order.
      </li>
    </ul>
  </li>
</ul>

<h3>Parallel Programming (Textbook / Course Projects)</h3>
<ul>
  <li>
    <strong>Description:</strong>
    Parallel programming assignments implemented using <strong>Pthreads</strong> and
    <strong>OpenMP</strong>, based on textbook and course-provided specifications.
    These projects focus on Monte Carlo simulation and numerical integration
    to study thread-level parallelism, synchronization, and performance.
  </li>

  <li>
    <strong>Examples:</strong>
    <ul>
      <li><code>PthreadsMonteCarloPI.c</code> – Monte Carlo π using mutex synchronization.</li>
      <li><code>pi_pthreads.c</code> – Monte Carlo π with per-thread data and execution timing.</li>
      <li><code>trap_pthreads_sem.c</code> – Trapezoidal rule using pthreads and semaphores.</li>
      <li><code>OpenMPMonteCarloPI.cpp</code> – Monte Carlo π using OpenMP.</li>
      <li><code>OpenMPAreaIntergration.c</code> – Trapezoidal rule using OpenMP.</li>
      <li><code>OpenMPVolumeIntergration.c</code> – Two-dimensional numerical integration.</li>
    </ul>
  </li>
</ul>

<h3>CPU Architecture Simulation (CPUSim)</h3>
<ul>
  <li>
    <strong>Description:</strong>
    A computer architecture project using <strong>CPUSim</strong> to design, implement,
    and test a custom CPU at the microarchitecture level.
    The project involved defining registers, datapaths, control signals,
    and microinstructions to execute arithmetic, logic, memory, and control-flow operations.
  </li>

  <li>
    <strong>Key Concepts:</strong>
    <ul>
      <li>Instruction set architecture (ISA) design</li>
      <li>Datapath components (registers, ALU, memory, buses)</li>
      <li>Microinstruction sequencing and control logic</li>
      <li>Load/store operations and arithmetic instructions</li>
      <li>Debugging execution at the clock-cycle level</li>
    </ul>
  </li>

  <li>
    <strong>Tools:</strong> CPUSim (Java-based CPU simulator)
  </li>
</ul>
